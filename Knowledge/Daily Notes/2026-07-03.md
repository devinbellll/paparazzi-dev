## Morning — Fixed PlotJuggler packet issue with wrapper tool

Wrote `pj_json_relay.py`: server.ml's UDP JSON stream has unescaped strings and
bare `nan`/`inf` floats (both upstream pprzlink bugs) that crash PlotJuggler's
UDP Server plugin. The relay sits in between, repairs/drops bad datagrams, and
also replaces the socat hop from the VM interface to localhost. Wired it into
`control_panel_mfc.xml` as a new session program.
