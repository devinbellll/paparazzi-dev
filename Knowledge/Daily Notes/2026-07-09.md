## Afternoon — Tuned and Worked with New Model

Two options for wiring MFC with new system:

Example z-axis:

$\ddot{z} = F + \alpha u$

1. 
	- u = [0 1]
	- alpha = max possible pseudo control (Fmot * 4)
	- allocation = [1 -1 1 -1] (just directional)

2. 
	- u = [min possible pseudo control (mass * 9.81)     max possible pseudo control (Fmot * 4)]
	- alpha = 1/mass 
	- allocation = controll effectiveness matrix

## Notes to Self


I have a theory about the alpha value for a thing with a delay

Need to actually calculate it though

alpha_T = 1 / airframe.m / (tau_m * (Ts * 5)); % GZ_ALPHA = 5

Essentially the statement: `alpha_T = 1 / airframe.m` is saying that the effect of the commanded force on the acceleration is slowed by 1/m (makes sense). But because we don't get the whole force right away we need to make the effect if of the commanded force make sense for what will be measured in the time window.

```
% MFC Thrust (gz) — GZ axis in guidance_mfc.c
% use_trajec_sp=false (guidance axis), use_Kd=false
FFilter_T = 5; % int_window = GZ_INTEGRATION_WINDOW = 4
WFilter_T = 50; % time_trajec = GZ_TIME_TRAJECTORY = 4
alpha_T = 1 / airframe.m / (tau_m * (Ts * 5)); % GZ_ALPHA = 5
kp_T = 2; % GZ_KP = 4
kd_T = 1.5;
command_filter_T = 1; % GZ_COMMAND_FILTER = 8
use_trajec_sp_T = false;
Umax_T = (9.81 * airframe.m);
Umin_T = -4*F_mot; % = -57.6
```
