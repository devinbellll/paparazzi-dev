## Notes to Self
- `nps_flightgear_init` uses `inet_addr()` — **never pass a hostname**, always a dotted-decimal IP
- Default NPS FG mode sends GUI protocol (version 8), FG expects FDM protocol (version 24) — **always pass `--fg_fdm`**
- Container firewall blocks `192.168.65.254` (Mac host) even though it allows the bridge gateway — `init-firewall.sh` patched to auto-allow `host.docker.internal` on startup
- XML comments cannot contain `--` (CLI flags in set file comments will break the parser)
- Verify pipeline: `nc -ul 5501 | xxd` on Mac, then "Address already in use" = FG is listening

```
--fdm=null \
--native-fdm=socket,in,60,,5501,udp \
--disable-ai-models \
--disable-sound \
--disable-random-objects \
--disable-real-weather-fetch \
--disable-terrasync \
--timeofday=noon \
--lat=45.0 \
--lon=-73.0 \
--altitude=0 \
--heading=0 \
--prop:/environment/atmosphere/is-isa=true
```
