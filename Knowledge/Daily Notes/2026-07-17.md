## Morning — Landing the units refactor and MFC_SISO rewrite

Finished porting MFC to physical units. Also did a big rewrite on the MFC_SISO controller this morning—modularised it, made it codegen-safe, and decoupled the feedback order from the model order so 1st and 2nd order plants both get full PID.

Guidance gains had been stale and needed updating for the new unit scheme anyway.

## Afternoon — Tuning and flying

Got Hoops flying in guidance mode in software-in-the-loop for the first time. Tuned x and y gains live—you can change values mid-flight and watch it respond immediately. Interesting bit: in MFC, changing KD doesn't add damping the way classic PD does; it's more like a modulation of the proportional term.

z axis was already holding, so left it static for now.
